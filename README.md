# Hong Kong, Neighbourhood by Neighbourhood

A mobile-first static guide with three half-day walking routes, restaurant recommendations, cultural notes, and an interactive map.

## Publish with GitHub Pages

This site is plain HTML, CSS, and JavaScript. It needs no build step. Once uploaded to a public GitHub repository, enable Pages from the `main` branch and the repository root.

The map uses Leaflet and OpenStreetMap tiles from public CDNs. Photo credits and research links are included in the page.
